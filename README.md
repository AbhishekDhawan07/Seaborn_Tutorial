## 📌 What is Seaborn

Seaborn is a Python data visualization library that provides a high-level interface for drawing attractive and informative statistical graphics.

It is widely used for:
- Data exploration
- Statistical analysis
- Creating visually appealing plots with minimal code

---

## ✨ Features

- 📊 Easy-to-use visualization library
- 🎨 Built-in themes and color palettes
- 📈 Statistical plotting support
- 🔍 Works seamlessly with Pandas DataFrames
- ⚡ Simplifies complex Matplotlib code

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/<your-username>/Seaborn_Tutorial.git
cd Seaborn_Tutorial
```

### 2. Install dependencies

```bash
pip install pandas numpy matplotlib seaborn jupyter
```

### 3. Run the notebook

```bash
jupyter notebook "Seaborn - Tutorial/Seaborn Tutorial.ipynb"
```
